# Tarneeb Online (৪ জন বন্ধু)

## ফোল্ডারে কী আছে
- `server.js` : খেলোয়াড়দের মধ্যে বার্তা পৌঁছে দেওয়ার ছোট সার্ভার (কোনো প্যাকেজ ইনস্টল লাগে না)
- `public/index.html` : পুরো গেম (আগের গেমটাই)
- `public/manifest.webmanifest`, `public/icon.svg` : ফোনে অ্যাপের মতো ইনস্টল করার জন্য

## ১. নিজের কম্পিউটারে চালানো
1. Node.js (১৮ বা নতুন) ইনস্টল করো।
2. এই ফোল্ডারে টার্মিনাল খুলে লেখো: `node server.js`
3. ব্রাউজারে খোলো: http://localhost:3000
4. একই Wi-Fi এর ফোনে খুলতে: http://<তোমার কম্পিউটারের IP>:3000

## ২. ইন্টারনেটে তুলে বন্ধুদের সাথে খেলা
যেকোনো Node হোস্টিং চলবে। সবচেয়ে সহজ উপায় (Render.com):
1. ফোল্ডারটা GitHub-এ আপলোড করো।
2. Render.com → New → Web Service → ওই রেপো বেছে নাও।
3. Runtime: Node, Start Command: `node server.js`, Plan: Free।
4. কিছুক্ষণ পর একটা লিংক পাবে (যেমন https://tarneeb-xyz.onrender.com)। সেটা বন্ধুদের পাঠাও।
5. একজন "Create table" চাপে, কোড বন্ধুদের দেয়। বন্ধুরা একই লিংক খুলে কোড দিয়ে Join করে।

ফ্রি প্ল্যানে কিছুক্ষণ কেউ না খেললে সার্ভার ঘুমিয়ে যায়, প্রথম খোলায় ৩০-৬০ সেকেন্ড লাগতে পারে। Railway বা Fly.io-তেও একই ভাবে চলে।

## ৩. অ্যাপ বানানো
- **সবচেয়ে সহজ (খরচ নেই):** ফোনের Chrome-এ লিংক খুলে মেনু → "Add to Home screen"। অ্যাপের মতো আইকন আর ফুল-স্ক্রিন খুলবে।
- **Google Play Store (Android):** Capacitor বা Bubblewrap দিয়ে ওয়েবসাইটটাকে APK/AAB বানানো যায়। Google Play ডেভেলপার অ্যাকাউন্টে একবার ২৫ ডলার লাগে।
- **Apple App Store (iPhone):** Capacitor + Xcode লাগে, তাই একটা Mac দরকার। Apple Developer অ্যাকাউন্টে বছরে ১৯৯ ডলার।
- দুই স্টোরেই প্রাইভেসি পলিসি, আইকন (৫১২×৫১২ PNG) আর স্ক্রিনশট লাগে।

## এখন যা সীমাবদ্ধ (আরও ভালো করতে চাইলে)
- খেলার হিসাব টেবিল-খোলা মানুষটার ব্রাউজারে চলে। সে পেজ বন্ধ করলে খেলা থেমে যায়।
- সবার হাতের কার্ড নেটওয়ার্কে চলাচল করে। কেউ ডেভেলপার টুল ঘাঁটলে অন্যের হাত দেখতে পারবে।
- ইন্টারনেট ৮ সেকেন্ডের মধ্যে ফিরে এলে সিট থাকে, বেশি দেরি হলে সিটে কম্পিউটার বসে।
- পরের ধাপ: গেমের হিসাব সার্ভারে নেওয়া (তাহলে চিট করা যাবে না, কেউ বেরোলেও খেলা চলবে), লগইন, চ্যাট, র‍্যাংকিং।
